# Battle Forge

Battle Forge — это веб-приложение для ведения боёв в настольной ролевой игре D&D. Проект помогает DM быстро управлять противниками, инициативой и уроном, не теряя внимание к сюжету и атмосфере игры.

## Что умеет проект

- управление списком противников во время боя;
- учёт инициативы и порядка хода;
- нанесение урона одному врагу или всем сразу;
- откат последних действий;
- отдельные интерфейсы для DM и для отображения на экране;
- современный интерфейс на Angular с адаптивным дизайном.

## Технологический стек

- Angular 20
- TypeScript
- RxJS
- Angular Fire
- Firebase Realtime Database
- SCSS
- Standalone Components

## Требования

Перед запуском убедитесь, что у вас установлены:

- Node.js 20+
- npm

## Установка

```bash
npm install
```

## Запуск разработки

```bash
npm start
```

После запуска приложение будет доступно по адресам:

- DM-панель: http://localhost:4200/dm
- Экран отображения: http://localhost:4200/display

## Доступные команды

```bash
npm start      # запуск dev-сервера
npm run build  # сборка проекта
npm test       # запуск тестов
```

## Структура проекта

```text
src/
  app/
    app.routes.ts      # маршруты приложения
    app.ts             # корневой компонент
    app.html           # шаблон приложения
    app.scss           # глобальные стили
  main.ts             # точка входа
```

## Разработка

Для локальной разработки достаточно запустить проект и открыть нужный маршрут в браузере. Если вы планируете расширять функциональность, лучше сначала изучить структуру компонентов и маршрутов в директории src/app.

## Лицензия

Проект распространяется как учебный или личный пример. При необходимости его можно адаптировать под свои нужды.
