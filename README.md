# Battle Forge

Battle Forge — приложение для ведения D&D-сражений в реальном времени.
Оно разделяет роли DM, игроков и экрана отображения, синхронизирует состояние боя через Firebase и помогает вести бой без бумажной рутины.

## Основные возможности

### DM-панель (`/dm`)

- добавление и удаление врагов;
- ручная настройка инициативы и сортировка порядка хода;
- запуск фаз боя: preparation, initiative, battle, ended;
- нанесение урона по одной цели или массово по всем живым врагам;
- переход хода, переход раунда, завершение и полный сброс сцены;
- выдача предметов игрокам (с количеством, описанием и редкостью);
- рандомизация действий/статусов/сопротивлений врагов;
- управление списком игроков в бою.

### Экран отображения (`/display`)

- живой список противников в бою;
- выделение текущего активного участника;
- карточки врагов: имя, тип, AC, HP, INIT;
- отображение действий, сопротивлений и статусов;
- крупный формат для второго монитора/TV.

### Интерфейс игрока (`/player`)

- вход по имени персонажа;
- загрузка JSON персонажа (LSS) и парсинг в нормализованную модель;
- просмотр характеристик, оружия, способностей и сопротивлений;
- синхронное обновление данных персонажа из Firebase;
- выбор цели и нанесение урона из вкладки арены;
- использование и изучение предметов в инвентаре.

## Синхронизация и состояние

- Firebase Realtime Database как источник истины для состояния комнаты боя;
- Signals (`signal`, `computed`, `toSignal`) для реактивного UI;
- компоненты работают как UI-слой, а бизнес-логика вынесена в сервисы.

## Технический стек

- Angular 20 (standalone components)
- TypeScript
- RxJS
- Firebase Realtime Database
- SCSS

## Архитектура (кратко)

Проект организован по слоям:

- `core/models` — типы домена (`Combatant`, `BattleRoom`, `ParsedCharacter`, `InventoryItem` и др.);
- `core/constants` — строковые и числовые доменные константы (`as const`), без enum;
- `core/services` — сервисы состояния, инициативы, урона, инвентаря, логирования, Firebase и парсинга персонажей;
- `core/utils` — общие утилиты (например, timestamp и сортировка инициативы);
- `features` — экраны `dm-control`, `display`, `player`;
- `shared/ui` — переиспользуемые UI-компоненты (`hp-bar`, `enemy-icon`).

## Требования

- Node.js 20+
- npm

## Установка

```bash
npm install
```

## Запуск в разработке

```bash
npm start
```

После запуска доступны маршруты:

- DM-панель: `http://localhost:4200/dm`
- Экран отображения: `http://localhost:4200/display`
- Интерфейс игрока: `http://localhost:4200/player`

## Скрипты

```bash
npm start        # ng serve
npm run build    # production build
npm run watch    # build в watch-режиме
npm test         # unit tests (Karma/Jasmine)
```

## Заметки по данным

- Состояние боя хранится в комнате `main-room`.
- Игроки хранятся в ветке `players`.
- Все обновления боя распространяются в реальном времени через подписки Firebase.

## Лицензия

Проект используется как учебный/пет-проект и может быть адаптирован под собственные нужды.
